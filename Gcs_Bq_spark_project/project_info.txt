cron job details:
------------------
automatically scheduling the Airflow DAG, rather than manually triggering it every day.

However, because your source file arrives daily in GCS, the pipeline should process data only after the expected file is available.

This schedules the DAG at 3:00 AM IST every day, giving the upstream process time to deliver the file.

Use the GCS sensor to wait for the daily file
For a file named products_2025-05-06.csv:


This assumes each 3 AM run processes the previous calendar day's file.
For example, a May 7 run checks products_2025-05-06.csv

prepare query for scd2 using merge query in Bigquery

MERGE `project.dataset.product_target` AS T
USING (
    -- 1. Identify changed records to expire
    SELECT
        S.*,
        'expire' AS merge_action
    FROM `project.dataset.product_staging` AS S
    JOIN `project.dataset.product_target` AS T
        ON T.product_id = S.product_id
        AND T.is_current = TRUE
    WHERE
        T.name <> S.name
        OR T.category <> S.category
        OR T.price <> S.price
        OR T.supplier <> S.supplier
        OR T.status <> S.status

    UNION ALL

    -- 2. Identify new and changed records to insert
    SELECT
        S.*,
        'insert' AS merge_action
    FROM `project.dataset.product_staging` AS S
    LEFT JOIN `project.dataset.product_target` AS T
        ON T.product_id = S.product_id
        AND T.is_current = TRUE
    WHERE
        T.product_id IS NULL
        OR T.name <> S.name
        OR T.category <> S.category
        OR T.price <> S.price
        OR T.supplier <> S.supplier
        OR T.status <> S.status

) AS S

ON T.product_id = S.product_id
AND T.is_current = TRUE
AND S.merge_action = 'expire'

-- 3. Expire the existing active record
WHEN MATCHED THEN
    UPDATE SET
        T.is_current = FALSE,
        T.effective_end_date = S.effective_start_date

-- 4. Insert new or changed records
WHEN NOT MATCHED BY TARGET
    AND S.merge_action = 'insert'
THEN
    INSERT (
        product_id,
        name,
        category,
        price,
        supplier,
        status,
        effective_start_date,
        effective_end_date,
        is_current
    )
    VALUES (
        S.product_id,
        S.name,
        S.category,
        S.price,
        S.supplier,
        S.status,
        S.effective_start_date,
        S.effective_end_date,
        S.is_current
    );
